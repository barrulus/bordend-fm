Nordend · 4609 m

A fast, native file manager for Wayland

Made for photographers. At home on any Wayland desktop, and right at home on Noctalia. No GTK, no Qt: C++20 straight on Wayland and OpenGL ES, with its own renderer for text, icons, scrolling and animation.

0.1.0, the first release. Young software, used every day by its author. To try it, build it from source; it takes about a minute.

Why Nordend

No toolkit at all

Nordend talks to the compositor directly. It takes your desktop's light or dark style and accent colour; on Noctalia it wears your Noctalia theme, live.

Photos first

Thumbnails, the preview pane and Quick Look read the previews cameras store in their raw files (OM System, Canon, Nikon, Sony, Fujifilm, Panasonic, Hasselblad), upright, with the shot's EXIF and your darktable rating.

Three views of one folder

Finder-style columns to walk a tree from the keyboard, a thumbnail grid to see a folder of photos, a details table to compare sizes and dates. Switching keeps your place and your selection.

Small, fast, measured

A 3 MB binary that starts in 128 ms from a cold cache, shows a 10 000-file folder at once and uses no CPU at all while nothing moves. Every number has a benchmark.

Natural scrolling

The touchpad moves the list 1:1 under your fingers and lets it glide when they lift; wheel and keyboard glide too. Nothing jumps.

Careful with your files

Nothing is overwritten without asking, nothing half-copied carries a real name, a real freedesktop trash, a card before anything is deleted for good, and Ctrl+Z for the last operation.

Build and install

Nordend builds with CMake and a C++20 compiler (developed with GCC 14), in about a minute on an 8-core CPU.

Requirements

  • Linux with a Wayland compositor that offers xdg-shell. Developed on Umbriel; also tried on GNOME, Plasma and niri (see Compatibility).
  • A GPU driver with OpenGL ES 3.0 (Mesa).

Build on Void Linux

sudo xbps-install -S cmake ninja pkgconf wayland-devel wayland-protocols \
    libxkbcommon-devel libglvnd-devel MesaLib-devel \
    harfbuzz-devel freetype-devel fontconfig-devel tomlplusplus-devel \
    libwebp-devel libjxl-devel exiv2-devel zlib-devel sdbus-c++-devel
git clone https://github.com/pankaspe/nordend-fm
cd nordend-fm
cmake -B build -G Ninja
cmake --build build
./build/nordend            # your home folder; ./build/nordend ~/Pictures for another one

Nordend is developed on Void Linux. On other distributions install the development packages of the same libraries; their names differ and have not been tried yet.

A package on Void Linux

An xbps-src template is in packaging/void. It builds the release into a package that puts nordend, its desktop entry and its icon under /usr:

git clone --depth 1 https://github.com/void-linux/void-packages
cd void-packages
./xbps-src binary-bootstrap
git clone --depth 1 https://github.com/pankaspe/nordend-fm /tmp/nordend-fm
cp -r /tmp/nordend-fm/packaging/void/nordend srcpkgs/
./xbps-src pkg nordend
sudo xbps-install -R hostdir/binpkgs nordend

Install it for your user

This puts nordend in ~/.local/bin, its desktop entry in ~/.local/share/applications and its icon in ~/.local/share/icons, so menus and launchers find it:

cmake --install build --prefix ~/.local --strip

To open folders in Nordend from other applications (a browser's "Show in folder", xdg-open), make it the default for folders:

xdg-mime default nordend.desktop inode/directory

Then bind it to a key in your compositor. In Umbriel's config.toml:

"Mod+E" = { action = "spawn nordend", repeat = false }

Using Nordend

Every action has a key and a click. F1 (or ?) shows all the keys inside Nordend; the same list is on the Shortcuts page.

Three views

  • Columns (Ctrl+1), as in Finder: every folder you pick opens in the next column. The arrows walk the tree; ← from the first column climbs to the parent. Drag a column's edge to resize it; the columns slide sideways by themselves to keep where you are in view.
  • Grid (Ctrl+2): large icons and thumbnails. Ctrl++ and Ctrl+− (or Ctrl+wheel) change the cells from 48 to 256 px; Ctrl+0 goes back to the usual size.
  • Details (Ctrl+3): a table of names, sizes, dates and types. Click a title to sort by it, again to reverse; drag a column's edge to widen it.

In any view, the context menu's Sort By sorts by name, size, date or type, ascending or descending. The order is the same in all three views and in every folder you open, and comes back at the next start.

The cursor and the selection go along between the three views. The bar at the bottom tells how many items there are, what is selected and how much space is left, and switches views with a click.

Moving and selecting

Click, Ctrl+click, Shift+click, or the keyboard alone: Shift+arrows for a range, Ctrl+arrows to move without selecting and Ctrl+Space to pick here and there, Ctrl+A for all, Escape back to one entry. With the mouse, drag from empty space (beside a name, below the entries, between the grid's icons) to draw a rectangle that selects what it touches, Ctrl to add to the selection; past the bottom or top the list scrolls. Enter or a double click opens: a folder in Nordend, a file in its application. Backspace goes to the parent folder.

Above every view the folder's path is a row of steps starting from your home: click one to go back up there, with the cursor on the folder you came from. Alt+← and Alt+→, or the mouse's side buttons, go back and forward through the folders you opened. Hidden files stay out of the way until Ctrl+H.

The sidebar

Your home and its folders (Downloads, Pictures...), the file system, the Trash, your bookmarks and the disks. Ctrl+B hides it, F6 takes the keyboard there and back. Ctrl+D, "Add to Sidebar" or a folder dragged there makes a favourite; favourites are GTK bookmarks, so the file choosers of other applications (Firefox's too) show them as well.

Disks plugged in show up without mounting themselves: a click mounts and opens one, the eject icon unmounts it and powers it off, ready to unplug (through udisks2).

The info pane

The pane at the right shows the file under the cursor: the photo itself, its size, pixels and dates, and for photos the shot (camera, lens, exposure, focal length, when, your darktable rating); text files show their first lines. "More details" opens permissions, owner and the rest. In the grid and the details Ctrl+I hides it; drag its edge to make it, and the photo, larger.

Quick Look

Space and the photo fills the window, raw files included. The arrows walk the folder without closing it, and the next photo is already there. Text files open on a page you can scroll, darktable sidecars included; everything else shows what it is, how big, whose and who may touch it. Space or Escape closes it.

Photos and raw files

Photos and camera raw files show their thumbnails upright in a fraction of a second: Nordend uses the previews your camera already stored in the file and keeps the thumbnails in the freedesktop cache that other applications read too. OM System, Canon, Nikon, Sony, Fujifilm, Panasonic and Hasselblad raw files show in the shape they were shot, without black bars.

darktable sidecars (photo.ORF.xmp, and the duplicates' photo_01.ORF.xmp) travel with their photo through every rename, copy, move, trip to the trash and restore, so no edit is lost.

Opening files

Enter or a double click opens a file in its default application, the same one GTK applications choose (checked on all 1 232 file types). Five photos go to one darktable, not five; terminal programs such as Helix get a terminal; the new window comes up in front. The context menu's Open With lists the same applications GTK would offer, for folders too. F4 opens a terminal in the folder under the cursor, else in the folder shown ("Open in Terminal" in the context menu); $TERMINAL chooses which one.

Renaming, new folders, copy and move

  • F2 turns the name into a field, the extension left out of the selection; Enter keeps the new name, Escape gives up. Nothing is ever overwritten.
  • Ctrl+Shift+N makes a new folder ready to be named; the context menu's New File makes an empty file or one from your templates folder.
  • Ctrl+C or Ctrl+X, then Ctrl+V. A move on one disk is instant; a copy runs as fast as cp, with its progress, speed and time left in the status bar. Nothing half-copied ever carries a real name, an original leaves another disk only once its copy is safely written, and dates and permissions stay.
  • A taken name asks: replace, skip or keep both, for one item or for the rest.

The trash

Delete moves files to the freedesktop trash, on their own disk, where any other trash program finds and restores them. The Trash in the sidebar shows every disk's trash as one folder; Restore puts things back where they were. Shift+Delete and Empty Trash delete for good, only after a card that says how many items and how many MB go.

Undo

Ctrl+Z undoes the last rename, move, copy, trashing or restore; Ctrl+Shift+Z redoes it. Copies and new folders are undone by moving them to the trash, never by deleting them, so even an undo can be undone.

With other programs

Files copied or cut in Nordend paste in another file manager, in Firefox or as paths in a terminal; files copied elsewhere paste in Nordend. Drag files from any view onto a folder, the path above or a place in the sidebar: on the same disk they move, onto another they copy (Ctrl copies, Shift moves), the Trash trashes them. Drag them into Firefox or a terminal, or from Firefox's downloads into Nordend. Folders change live when other programs create, remove or rename files.

The context menu

A right click, a two-finger tap, Menu or Shift+F10. Every action in it shows its shortcut.

Look and memory

With Noctalia, Nordend wears your Noctalia palette and follows it live. On GNOME or Plasma it follows the desktop's light or dark style and accent colour, live too. Where the compositor draws no title bar Nordend draws its own; where it offers no cursor shapes Nordend draws them from your cursor theme. The view, the order, hidden files, the sidebar, the info pane, column widths and the window's size come back at the next start.

Configuration

Nordend is ready as it starts: the system's fonts and the desktop's colours. There is no settings window; the few settings there are live in one file.

config.toml

~/.config/nordend/config.toml (or $XDG_CONFIG_HOME/nordend/config.toml). Every key is optional; a bad value is reported in the log and keeps its default. Nordend reads the file again when it changes: the double click at once, the fonts at the next start. nordend --check-config checks a file without starting Nordend.

Colours

With ~/.config/nordend/colors.toml (the palette's colours by name, which Noctalia can write from its theme through a user template; a template for Noctalia itself is planned), Nordend uses that palette and follows every change live. Without it, Nordend follows the desktop's light or dark style and accent colour through the freedesktop portal (GNOME, Plasma); with no portal, Noctalia's default palette.

Architecture

One process, one window thread, a pool of workers. No toolkit: Nordend draws everything with OpenGL ES and shapes its text with HarfBuzz.

Threads and frames

  • The window thread waits in a single poll() on Wayland, the workers' results, inotify, D-Bus and timers.
  • Workers do the I/O, decoding and thumbnails. Jobs have priorities (visible, nearby, prefetch) and are cancelled when what they were for scrolls away.
  • A frame is drawn only when something changed or is moving, and at most one is in flight, paced by the compositor. An idle window draws nothing and uses no CPU.
  • Decoded photos go back to the system once they are on the GPU.

Safe file operations

  • Copies go into a hidden temporary file (copy_file_range) and take their name only when complete, with renameat2 refusing to replace anything.
  • A move across disks removes the original only once its copy is written.
  • Deleting for good is planned on a worker and always confirmed first.

Quality

  • 274 test cases (doctest), run under AddressSanitizer with UBSan and under ThreadSanitizer before every commit; clang-tidy and clang-format on every change.
  • Drawing is checked offscreen: nordend-snapshot renders the real views through a surfaceless EGL context, without a window.
  • Vendored code (the wuffs decoders, a subset of Tabler Icons, Noctalia's default palette) is listed with its origin and license in THIRD_PARTY.md.

Roadmap

One step at a time, each closed only when it is tested on real hardware. What was done, measured and decided at each step is in the devlog.

Now

  1. Tabs (Ctrl+T): a new tab on the folder shown, Ctrl+W, Ctrl+Tab, Alt+1…9, a middle click on a folder; each tab with its own history and view, remembered at the next start.

0.1.0, the first release, came out after a week of daily use by the author, with a memory log: no bugs found, memory steady.
